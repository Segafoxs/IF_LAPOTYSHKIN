# Автотест API

Данный проект создан для изучения автотестирования.


## Используемый стек

В данном проекте были использованы следующие инструменты и фреймворки:

- Java
- Maven
- Junit5
- REST Assured
- Cucumber
- Allure Report


## Установка

- Склонируйте данный проект

```bash
  git clone https://github.com/Segafoxs/IF_LAPOTYSHKIN
```
- Запустите класс CucumberRunnerTest
- Сгенерируйте отчет
```bash
  mvn allure:"report"/"serve"
```
