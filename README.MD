# Автотест API

Данный проект создан для тестирования UI Jira.


## Используемый стек

В данном проекте были использованы следующие инструменты и фреймворки:

- Java 17
- Maven
- Junit5
- Selenide
- Allure Report


## Установка

- Склонируйте данный проект

```bash
  git clone https://github.com/Segafoxs/IF_LAPOTYSHKIN
```
- Запустите класс AutoTest
- Сгенерируйте отчет
```bash
  mvn allure:"report"/"serve"
```
